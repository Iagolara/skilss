# Instruções do projeto Eletrohome

- Responda sempre em português do Brasil.
- Em toda tarefa, siga a skill `economia-de-modelos` (em `.claude/skills/economia-de-modelos/SKILL.md`): delegue o trabalho simples a subagentes com modelo mais barato (Haiku/Sonnet) e reserve o modelo principal para análise, decisões e uso do computador. Esta instrução autoriza o uso de subagentes para isso.
